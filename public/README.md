# Static files

The app uses `public/assets/tractate.svg` for its logo and favicon, and `public/assets/tractate.png` for its PNG and Apple touch icons. Other static files can go under `public/assets/` as well.

Astro copies `public/` unchanged into the built site. For a logo at `public/assets/logo.svg`, the URL is `/assets/logo.svg` locally, or `/tractate/assets/logo.svg` when hosted under `/tractate/`. Use `import.meta.env.BASE_URL` when referencing it in the app.

`public/preview.html` is generated by the build. Do not edit it manually.
